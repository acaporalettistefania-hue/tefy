# VAS Beauty Store

Tienda online de demostración para productos de pestañas y cejas. Proyecto educativo realizado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura de la tienda.
- `styles.css`: diseño visual y adaptación a celulares.
- `script.js`: catálogo, filtros, búsqueda, favoritos y carrito.

## Funcionalidades
- Catálogo con imagen, nombre, categoría, descripción y precio.
- Búsqueda por nombre o descripción.
- Filtro por categoría.
- Carrito con cantidades, eliminación y total automático.
- Mensajes al usuario.
- Favoritos.
- Modo oscuro.
- Guardado del carrito y favoritos con `localStorage`.

## Cómo probarlo
1. Descargá o descomprimí la carpeta.
2. Abrí `index.html` en un navegador.
3. Para cambiar productos, precios o imágenes, editá el arreglo `products` al comienzo de `script.js`.

Los importes y productos son de ejemplo y se pueden modificar. Las imágenes se cargan desde internet, por lo que se necesita conexión.

## Publicar con GitHub Pages
1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html`, `styles.css`, `script.js` y `README.md`.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. GitHub mostrará el enlace público de la tienda en esa misma sección.

## Uso de inteligencia artificial
Se utilizó inteligencia artificial como apoyo para proponer la identidad visual, generar una primera versión del código, organizar las funciones de JavaScript y explicar cómo publicar el proyecto. El código debe ser revisado y comprendido por el alumno antes de la entrega.

## Explicación breve
HTML organiza las secciones y los productos; CSS define los colores, tipografías, tarjetas y diseño responsive; JavaScript permite buscar, filtrar, guardar favoritos y administrar el carrito. `localStorage` conserva el carrito y los favoritos aunque se cierre o actualice la página.
